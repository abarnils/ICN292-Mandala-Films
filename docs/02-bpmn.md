# Procesos BPMN

## AS-IS
El BPMN As-Is muestra la forma en que se realiza hoy la gestión de proyectos en Mandala Films, abarcando desde que se recibe la solicitud de cotización hasta que se llega al cierre del proyecto. Para esto, el modelo incluye tres polls principales que correponden a Cliente, Mandala Films y Facturacion.cl. A su vez, el área de Mandala Films se divide en las Lanes de Dirección/Productor, Equipo Audiovisual y Administración y Finanzas,  lo que ayuda a delimitar las tareas comerciales operativas y administrativas del proceso. 
La estructura generael abarca 6 etapas consecutivas. La primera es cotización y aprobación, en la cual se evalúa si el proyecto se sigue adelante. Luego viene la Planificación, que sirve para organizar los requerimientos junto con el plan de trabajo después está Guion y Aprobación donde se revisa la propuesta creativa de manera previa a grabar. La cuarta etapa es Producción y postproducción, momento en que se ejecuta el trabajo y se deja listo el material final. Le sigue Entrega y facturación, donde junto con enviar el resultado se gestiona la documentación requerida para facturar. Por último Pago y cierre, fase enfocada en registrar el pago para dar por finalizado el proyecto.
De este modo, el diagrama As-Is ayuda a entender de que manera se reparten las actividades entre los actores involucrados. Asimismo, deja ver donde se origina el problema de gestión de información debido a que el seguimiento del trabajo todavía se maneja de manera manual y apoyándose con herramientas independientes entre sí.
